## About Me

I'm Renfred, a Computer Science student at the University of Toronto Mississauga and a Lester B. Pearson International Scholar.

I'm interested in building software, machine learning, and using technology to solve problems that actually matter. I enjoy working across the stack — from designing how a product should work, to writing the backend and frontend, to deploying it and seeing people use it.

I've built and experimented with projects spanning education, AI, developer tools, and productivity. Some of my current work includes Examina, an assessment and grading platform for universities; IsScamCheck, an AI-powered tool for evaluating potentially deceptive online policies; and Navix, a browser-based command hub.

I'm also interested in the intersection of computer science, mathematics, AI, and entrepreneurship. Long term, I want to build products and companies rather than simply write code for them.

Outside of tech, I casually play chess and I'm always trying to learn something new.

I care about building things that are useful, shipping them, and continuously getting better.
